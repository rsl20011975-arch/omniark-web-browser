## Structure and contracts
- src/native: extension build, session bridge, HTTP bridge routes
- src/extension: MV3 service worker, observed DOM tools, native sidepanel bootstrap
- src/engine: queue/steer execution state, shared tool dispatch
- src/integrations: external stdio MCP/CLI clients using same authenticated engine
- docs/acceptance: fixed 50-feature ledger, explicit evidence, no partial pass credit

Native side panel displays local chat beside REAL Chromium tabs. Extension commands
are observed fixed browser operations, never arbitrary JavaScript sent by a model.
Requests carry operation UUID, observation ID, selected tab and browser session.
Bridge binds only loopback, origin allowlist plus per-start random secret; unpaired
pages cannot enqueue commands. One agent owns a run; manual tab changes invalidate
observations and require fresh observation. Separate native profile never attaches P0.

## Acceptance
Goal: same-window actual browser + conversational file workflow and shared tools.
Audience: Dream, local Windows single user.
Deliver: native side panel, working actual tab, queue/steer, scoped external bridge.
Pass: own fixture + public page navigation/click -> files/revision in this profile,
real side-panel open state, wrong observation refused, queue order retained.
Fail: screenshot substituted for tab, hidden origin mismatch, fake model/evidence.
