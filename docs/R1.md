# R1 implementation contract

Approved design: ../../../outputs/Aside 실사용 기반 통합 작업환경 재설계.md

## First delivery
Natural Korean chat -> observed browser interaction -> verified local text/CSV/Markdown
artifact -> follow-up replacement with expected hash, original version retained.
No keyword demo planner. Official Codex CLI produces validated structured tool calls.

## Boundaries
- src/contracts: strict request/tool schemas shared by adapters and engine.
- src/agents: official Codex CLI inference only; no arbitrary command tools.
- src/browser: exclusively owned R1 Chromium context, never diagnostic/p0 attachment.
- src/files: one allowlisted artifact directory, flat filenames, hash conflict checks.
- src/engine: serial run owner, SQLite messages/events, no silent replay after restart.
- src/server: loopback-only authenticated API with same-origin mutation checks.
- src/ui: approved A/C visual language, live screenshots + chat + artifact previews.
- tests: owned fixture, actual model integration, persisted artifacts and revision checks.

Input: message, conversationId. Tools: navigate, observe, click, fill, save, finish.
Every tool output is recorded; file writes return sha256 and version. Missing/empty
outputs and changed files are failures. Page text is untrusted input, never instructions.

## Runtime decision
R1 is explicitly a compatibility bridge using the pinned official Chromium binary
and a local workbench. It is NOT the final patched Chromium WebUI shell. The existing
native-control denial is not bypassed: the diagnostic profile is never attached.
Testing operates on a newly owned profile and authored fixture; production Flow is
not part of this R1 verification. Final Chromium build must rerun the same acceptance.

## Acceptance
Goal: one real browser/file conversational workflow. Audience: local single user.
Deliver: working panel, actual browser, persisted chat and versioned files.
Pass: real model navigates, clicks fixture control, reads 10 records, writes CSV;
follow-up edits same file with correct 10 rows and retained original. Restart retains.
Fail: mocked model, fake screenshot/result, only regex commands, missing file, lost rows.

Sources checked 2026-10-18: https://developers.openai.com/codex/noninteractive,
https://playwright.dev/docs/library, https://vite.dev/guide/.
The product uses installed official CLI login; never reads/copies authentication tokens.
